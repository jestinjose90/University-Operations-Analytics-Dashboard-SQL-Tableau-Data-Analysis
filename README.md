# University Operations Analytics Dashboard

## Project Overview

The University Operations Analytics Dashboard is a data analytics project focused on understanding course scheduling, classroom utilization, instructor workload, and student enrollment patterns.

The goal of this project is to transform university operational data into meaningful insights that can help identify scheduling patterns, evaluate classroom usage, and understand course demand.

Using SQL for data analysis and Tableau for visualization, I developed an interactive dashboard to explore key operational metrics and answer important business questions.

## Tools & Technologies

- **SQL (MySQL):** Data exploration, joins, aggregations, CTEs, and analysis
- **Tableau Public:** Interactive dashboards and data visualization
- **Excel/CSV:** Data export and preparation
- **Python:** Supporting dataset generation

## Business Questions

This project explores the following questions:

1. How many classrooms are available?
2. How many classes are scheduled across departments?
3. Which classrooms have the highest number of scheduled classes?
4. What percentage of classrooms are underutilized?
5. How many instructors and scheduled classes are there in each department?
6. Which courses have the highest student enrollment?
7. Which day has the highest number of scheduled classes?
8. What are the scheduling patterns by day and starting hour?

## Key Analysis

- Analyzed classroom scheduling frequency to understand how frequently rooms are assigned.
- Categorized classrooms based on the number of scheduled classes.
- Compared instructor distribution and scheduled classes across departments.
- Evaluated course enrollment to identify courses with higher student demand.
- Examined scheduling patterns by day and starting hour to identify peak scheduling periods.

## Dashboard Features

- Total classroom count
- Total scheduled classes
- Total instructor count
- Classes scheduled by department
- Classroom utilization categories
- Instructor distribution by department
- Course enrollment analysis
- Peak scheduling day
- Class scheduling patterns by day and hour

This is a portfolio project using a college dataset supplemented with generated supporting data for instructors, classrooms, and schedules. The data is intended for analytical demonstration and does not represent actual university operations.

## Conclusion

This project demonstrates how SQL and Tableau can be used together to analyze university operations, identify scheduling patterns, and present findings through an interactive dashboard.
